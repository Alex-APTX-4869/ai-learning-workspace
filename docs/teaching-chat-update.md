# 讲课对话与自动补问（2026-09-10）

- 讲课时隐藏课程抬头、知识点侧栏、阅读工具和页脚，仅保留顶部卡片对话导航、退出按钮、消息区和固定输入区。退出或按 Esc 先恢复阅读模式，再关闭学习弹窗。
- 每次展示一张卡片；下一张打开该卡片的对话。顶部仅列出已经打开的卡片，回看不会重复建立对话或调用模型。问答仍按内容版本和卡片标识保存。
- 对话切换使用版本检查和请求编号去重，讲师回答期间禁止切换，避免回答错位。
- 访谈 Agent 发现关键歧义时自动补问一道，预算加一，展示原因。不再要求批准。初始深度仍为 1–20 题，后续必要补问可以超过初始预算。
- 同一补问的答案提交与预算更新在同一事务完成；旧等待审批的会话通过显式恢复接口自动接续，重复恢复不会重复加题。
- 本次不改课程范围扩充、补充章节的审批规则，也不代表资料检索和讲师 RAG 后续阶段已经完成。

验证：前端构建、学习组件回归、后端临时数据库测试；本地真实页面验证逐卡切换、单一滚动区域、固定输入区及退出恢复。没有调用真实付费模型进行评测。
