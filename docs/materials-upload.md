# 上传资料与创建课程（2026-09-09）

已完成 M3b、M3c 文字检索及初步的资料感知访谈，不代表整个 M3—M6 已完成。

## 使用路径

1. 首页点击“创建课程”，填写课程想法，在同一表单上传资料。
2. 本机解析后，为文件指定总述、章节或补充参考用途；PDF 可将不同物理页段分给不同章节。停止输入约 650 毫秒后自动保存，无需逐份点击保存按钮。未填写完整的章节名/页码会就地提示，保存完成后才能进入下一步。
3. 查看提取文字和原页。PDF 可逐页视觉识别，核对通过后点击“本次课程采用此页”。其余有识别缺口的页，须明确同意仅采用已提取文字，或者缩小页段/排除文件；纯扫描 PDF 也可借助已采用转录进入分析。独立图片尚不能走这条 PDF 单页链路。
4. 声明本批是部分还是全部资料，点击“核对范围，准备分析资料”。查看服务商、片段数和请求次数上限，再点击开始分析。
5. 分析完成后，点击“让 AI 帮我理清需求”。资料摘要、标注和覆盖声明进入每轮访谈及最终需求档案，资料内容不能被当作学习者已有能力。
6. 确认创建课程后，可在“参考资料”栏回看这批资料。资料范围从进入访谈起固定；现有课程追加资料的版本流程尚未开放。

## 当前能力边界

- PDF：文本、物理页码、原页 PNG、原生目录；可手动确认识别单页、核对并明确采用，转录修订随后进入需求分析、课程生成及来源读取，详见 `document-recognition.md`。
- DOCX：段落、标题路径、表格、原始 OMML 公式及图片线索。公式不扁平化成误导文本，脚注等未覆盖部分有报告。
- PNG/JPEG：保留原件和预览，尚无 OCR/视觉描述。
- DOC：保留原件，明确提示转换能力未通过验收，请另存为 DOCX/PDF。
- 文件真实解析，模型调用使用配置的真实服务商；生产界面没有模拟内容。回归测试中的合成资料和模型替身不代表教学质量验收。
- 分段摘要属于资料总览，不是 RAG 原文检索，也不能据此宣称精确引用。额外章节审批、向量索引、局部补料和讲师查证仍在后续阶段。

## 原文检索（2026-09-10）

进入课程 → 参考资料 → 查找资料原文。可输入中文关键词、函数名、错误码；选择 PDF 文件和物理页码后，也可留空关键词直接读该页。搜索结果显示文件、页码或 Word 段落，点击“查看原文与出处”读取上下文；长段可继续读取，解析器保留原页时可展开预览。结果预览只展示前五行，原文不会因此截断。

搜索和读取均限制在当前目录版本确认的文件、页段、解析修订和已采用视觉转录修订内。没有关联资料的旧版本不会自动借用新版资料。底部完整解析报告供用户人工核对，可能包含未纳入课程的页；它不是 Agent 的检索范围。搜索不触发新的图片识别、不进行向量化；内容制作可读取有限命中片段并冻结引用，讲师沿用这些片段，不会自动再次检索。

当前使用英文标识符和中文双字片段匹配、轻量排序；不是语义检索。没有命中不表示资料中不存在相关概念。当前搜索不调用模型，不收费；下一步仍需视觉解析、索引/质量评测及讲师按需查证。

## 后台、恢复与范围控制

### 标注自动保存（2026-09-13）

- 显示等待保存、正在保存、已保存、填写不完整或保存失败状态。网络失败不无限重试；用户可重试，或明确放弃未保存修改。
- 多份文件的修改串行提交；保存请求中的快照与继续输入的新草稿分开。后台解析轮询不能覆盖未保存的输入，版本冲突不会自动覆盖另一处编辑。
- 未完成和失败的标注临时保存在当前浏览器、当前站点的 localStorage，关闭再打开可恢复；服务端确认成功后清理相应草稿。浏览器存储不可用时明确提示，清除浏览器数据仍会丢失尚未提交的编辑。
- 自动保存只保存用户填写的标注。不会代勾“仅采用文字”，不会启动模型分析，也不会跳过发送服务商及费用说明。进入分析前仍需明确点击“开始分析资料”。
- `npm run test:autosave` 覆盖防抖、字段校验、请求中继续编辑、失败重试、轮询/版本冲突、关闭恢复、旧响应不清除新草稿、只读状态及跨文件串行保存；不调用模型或修改真实资料。

原文件和每次解析修订分别保存于 `.material-storage/`，数据库记录文件哈希、页段标注、处理报告及分析检查点。备份资料时需要同时备份数据库和该目录；单独 pg_dump 不包含原文件。

关闭弹窗/刷新只停止页面轮询，不取消后台任务。确定性解析在服务重启后重新排队；模型请求结果不明时标记为“需要处理”，只在用户明确重试后再次调用。已成功的同输入、同模型配置摘要会复用，不能承诺中断时零重复计费。

编辑采用版本校验；上传使用请求标识去重。分析前的资料清单和模型路由固定，后来改全局配置不会悄悄改变此次分析/访谈的服务商。另一课程、排除文件及未选页段不会进入这批摘要分析。

解析子进程使用独立 `.venv-materials`（固定依赖见 `materials_runtime/requirements.txt`），不继承凭据、禁止联网，仅能读系统依赖、解析包及本次作业目录；应用其余文件不开放给解析进程。仅当前 macOS 隔离方案通过测试，其他平台会明确停止，不会裸跑。

资源限制是运行预算，不是对课程章数的暗示：每文件 25 MB、每批 30 文件/200 MB、每 PDF 最多 150 页、每批最多 64 个分析片段。每片段按序列化后的文字和定位元数据计量，不是只算正文。分析总览超预算会明确失败，不截断后半份资料。
