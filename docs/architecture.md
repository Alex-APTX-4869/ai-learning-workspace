# 璃云白 · 个人 AI 学习工作台

## 已确认的产品方向

- 个人使用，暂不做账号、权限和多用户。
- 每门课程是一张可进入的卡片；课程内部展示章节、小节。
- 先生成章节和小节，再按章生成知识点。生成成功自动保存。
- 点击小节，打开学习弹窗：左侧知识点列表，右侧当前知识点的内容。
- 内容制作采用“规划者 → 作者 → 审查者”；先规划同一小节的讲解范围，再按知识点生成正文。
- 学习内容包括讲解、示例、练习及答案；适合编程的知识点提供 Python 练习。
- 每门课程可拥有参考资料库。引用必须可追溯；允许扩展，扩展部分标为“AI 补充”。
- 璃云白主题：冷白背景、白色面板、深灰文字、克制的雾蓝强调色。

## 目录与职责

```text
backend/
  main.py                 # 创建应用、注册路由；不写业务逻辑
  database.py             # 数据库连接、会话、模型基类
  core/config.py          # 读取环境配置
  courses/
    models.py             # 四层数据库表
    schemas.py            # 摘要、详情、请求的数据约定
    service.py            # 查询、创建、保存课程
    router.py             # 课程 HTTP 接口
  ai/
    client.py             # 统一模型调用、超时和错误处理
    prompts.py            # 提示词
    schemas.py            # 模型生成结果的结构
    service.py            # 大纲与知识点生成
    router.py             # AI HTTP 接口
  tests/                  # 有业务意义的接口和保存回归测试
frontend/src/
  App.vue                 # 应用外壳与页面切换
  pages/
    CourseLibrary.vue     # 课程卡片页面
    CourseWorkspace.vue   # 课程目录页面
  features/
    courses/
      api.ts              # 课程请求
      types.ts            # 课程数据类型
      useCourses.ts       # 课程状态与异步操作
      components/         # 卡片、课程表单、章节列表
    learning/components/  # 学习弹窗、知识点导航与正文
    materials/components/ # 参考资料入口
  shared/
    api.ts                # 请求与错误处理
    components/           # 通用弹窗、图标
    styles/               # 主题、全局基础样式
docs/
  architecture.md         # 产品边界与结构约定
  agent-roadmap.md        # 内容制作、资料库、代码练习的实施设计
```

后续真正实现时，再创建 `backend/materials/`、`backend/learning/`、`backend/workflows/`。不提前堆放空实现；先在设计文档中明确接口与数据归属。

## 依赖规则

页面 → 功能组件/状态 → 功能 API → 共享请求函数。

后端路由 → 业务服务 → 数据库/AI 客户端。提示词不放路由中。AI 不直接写数据库，校验后的结果由课程业务服务保存。前端只保存显示状态，数据库保存课程内容。首页只加载课程摘要；进入课程才获取完整目录。知识点正文加入后继续按点加载。

同一数据类型只有一个定义位置；组件通过参数接收数据，通过事件通知操作。单个文件若同时处理布局、网络、数据整理和提示词，优先按职责拆分，而不是按行数机械切割。

## 本轮实施边界

本轮交付课程管理界面、学习弹窗、后端模块化和已有生成结果的数据库保存。保留原先的 AI 生成接口兼容已有调用，新增按课程 ID 定位并保存的生成接口。

资料上传检索、完整讲义/练习制作、运行 Python 和 AI 辅导属于后续阶段。界面中未实现的功能明确说明状态，不显示虚构内容或模拟成功。已有知识点简介能在弹窗中真实阅读。

生成中的错误不清除既有内容；不同课程的请求按课程 ID 归属。已有大纲和知识点不自动覆盖，重生成/版本管理另行实现。原项目已有环境配置、虚拟环境、JavaScript 备份保留。
