# 目录归组与新增章节

## 使用

1. 首次无目录版本时入口显示“生成课程大纲”；已有版本才显示“重新生成课程大纲”。
2. 在课程目录的版本栏点击“增加章节”，输入章节名称和学习要求。
3. 可以不上传资料；也可以上传新文件、自动保存用途/章节/页段标注，核对解析结果并完成资料分析。
4. 点击“生成新章节预览”。这一步只生成一个章节及其小节，不修改当前目录，不生成正文。
5. 确认预览后加入课程，产生并选中新版本。原节点 ID、原资料范围、旧版本和已有知识点内容保留。
6. 点击新章的“生成知识点”，再进入小节制作讲解。知识点上下文和内容原文检索都会使用该目录版本的资料。

生成预览后资料批次冻结；不满意可选择“不采用此预览，重新填写”。新草稿需要重新选择资料，不会把已冻结批次的标注悄悄改掉。关闭重开可恢复预览。首次请求网络结果不明时会读取服务端草稿；失败后显式重试，不自动重复调用模型。

## 实现边界

- 同一个显式“第 N 章”生成事件归入同一个章节，下游小节事件带同一 chapter_index。界面更新标题时不清空已收到的小节。未标明原章号的不同章节不会按相似名称猜测合并。
- 人工局部草稿基于固定 base_version_id。发布前检查当前选择的目录版本，禁止静默合并到已变更的基线。
- 新资料通过 directory_draft_materials 绑定到课程和草稿；一批不能被不同草稿重复认领。
- 发布后的 brief.material_basis.batches 保存原批次和追加批次快照；检索逐批验证课程归属、解析版本、文件哈希、标注与视觉采用版本。旧版本不会读到未来追加的资料。
- 增加章节目前同步生成预览，资料解析/分析沿用持久后台任务。预览生成尚非独立持久生成队列，不承诺进程崩溃后自动继续模型调用。
- 本次没有新增全 PDF 自动视觉识别或向量检索。
