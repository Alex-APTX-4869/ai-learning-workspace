# 基础版本真实模型验收

## 范围与保护

运行工具：`scripts/accept_basic_live.py`。必须显式提供 `--run-real-models` 才会调用当前已配置模型；普通自动化测试不会触发调用。

- 正式数据库只读取模型连接与全局职责配置，不复制用户课程，不更改配置或钥匙串。
- 独立 SQLite、资料及结果放在 `tmp/basic-live-*`；测试使用本项目的合成 PDF，不上传私人教材。
- 使用正式解析器、提示词、模型客户端、业务接口与生成工作流；测试库中手动领取任务，不启动正式队列。
- 默认至多 24 次模型调用，不自动整轮重试；保存角色、耗时、可用 token 用量、生成结果与验收检查，不记录密钥或供应商原始错误正文。
- `software_flow_passed` 只代表此次抽样软件链路通过，不代表教学质量自动合格，更不代表整门课程或所有文件类型均通过。

## 运行

在项目根目录使用现有 `.venv`：

```sh
.venv/bin/python scripts/accept_basic_live.py --run-real-models
```

依赖已安装的独立资料解析环境及 `tmp/material-fixtures-m3a/core/lecture.pdf` 合成文件。若需要继续已完成大纲与知识点的测试，可显式使用 `--resume-content tmp/basic-live-具体目录`。调用计数会沿用，不重新上传和重做访谈。

知识点生成会返回新的目录版本。验收和前端都必须使用返回的 `outline_version_id`，不能将新知识点 ID 与旧目录版本混用。

## 页面验收

`scripts/preview_basic_live.py tmp/basic-live-具体目录` 只打开上述测试库，绑定本机 8002 端口。另开临时前端代理到该端口，不改变日常使用的服务。预览禁止生成、上传和修改模型配置；允许翻阅测试课程及学习卡片。

检查：选中的资料页段、来源定位、关闭弹窗后任务继续、重新进入恢复对话、一次只打开一张卡、输入栏不跟随正文滚动。

## 质量检查

- 摘要：有没有把未选页、不可识别图表或未提供正文当成已读？
- 需求：有没有重复提问、臆测学习基础，或把资料缺口误写成用户不学的范围？
- 大纲：时长是否可行？同一任务的操作与原因是否被无谓拆开？
- 内容：必要概念是否解释清楚？独立示例是否真的增加理解，而非复制讲解？
- 练习：按教学需要安排；真实生成后再核对题型、选项、答案和解析，不把“本点不需要”算成题目质量已通过。
- 讲师：是否针对问题解答，是否越权翻页，是否谎称执行代码或读取原文？
