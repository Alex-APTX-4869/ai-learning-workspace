# 文档识别配置与接入边界

## 已实现：独立的模型用途分配（2026-09-14）

入口：模型与 API → 职责分配 → 文档识别。配置区常驻显示，不再藏在高级设置里。

复用原有 `materials.vision` 路由及已有绑定，无需迁移或重复保存 API Key。用户可以复用现有连接中的视觉模型，也可以新建专用连接；该职责继承默认视觉模型，但单独指定不会改变资料摘要、课程生成或讲师的分配。仍支持全局和课程范围。

先在“连接与模型”声明文字对话、结构化结果、图片理解，再点击“检测文档识别能力”。该操作复用已有后端探测端点，只请求这三项能力，最多三次请求：测试文字和本机合成的随机四色图，不使用用户资料。服务方可能计费；页面明确说明后由用户点击触发，不自动测试、不伪造 verified 状态。看图能力未验证或已失败的模型不能绑定。

检测只验证基础图像输入/回答及简单结构化输出，并不是 OCR、数学公式、表格或整份教材的准确率验收。当前仅支持带图片输入的 OpenAI 兼容模型接口，其他 OCR 厂商专用接口需另做适配。

## 已实现：单页识别与人工核对（2026-09-14）

上传 PDF 并完成本机解析后，在文件卡片点击“识别与核对单页 PDF”。创建课程表单和课程参考资料都可进入。

1. 选择 PDF 物理页码。打开页面只读取本机预览、文字及已保存结果，不调用模型。
2. 点击“核对发送范围”，查看接收服务商、模型、接口地址、图片大小、同页辅助文字量及请求次数。用户确认后，才发送该页全部图文，不发送整份 PDF。
3. 持久后台任务固定本次模型配置及源页哈希，最多调用一次模型，失败不自动重试。关闭窗口不取消；服务中断且结果未知时需手动重试，不能承诺中断后零重复计费。
4. 双栏查看原页和转录结果，支持文字、LaTeX 公式源码、Markdown 表格及图示说明；存疑内容单独标记。用同一条外层滚动，不给两栏各加纵向滚动。
5. 可填写备注并标记“核对通过”或“识别有误”。核对本身仅记录判断；在编辑中的资料草稿里，再点击“本次课程采用此页”，才将当前修订加入后续分析。标记有误后可以重新确认并重试。

客户端在发送前保存请求标识，网络结果未知时恢复同一请求；同一输入、模型配置和提示词版本下已有可用任务会复用。运行预算：单页 PNG 不超过 8 MB，同页文字不超过 24000 字，输出不超过 100000 字；超限明确报错，不静默截断。模型请求超时最多 180 秒、输出 token 最多 12000，受用户配置的更小预算约束。

新增迁移 `20260914_05_page_recognition` 只创建识别任务表。模型原始异常不回显，路由快照不存明文密钥。接口遵循[官方图片输入格式](https://developers.openai.com/api/docs/guides/images-vision)，仅支持相应 OpenAI 兼容接口，不能保证任意厂商兼容。

## NUS 真实模型小样本（2026-09-15）

经用户授权，先测试 `.env` 指定的 `qwen3.6:27b`，没有发送私人教材。随机四色图按顺序识别通过；用 `scripts/render_vision_sample.py` 生成的合成页，仅发送 PNG、不提供辅助文字，通过实际 `vision_client.recognize` 接口调用，在约 9.1 秒内得到：

- 分式 `y = (x² + 3) / 2` 正确转为 LaTeX，保留平方和分母。
- 表格列名、毫秒单位和 A=17 / B=42 对应关系正确。
- Input → Model → Result 节点与箭头方向正确。

随后通过应用的文字、结构化结果、图片理解能力探测，将同一 NUS 模型作为独立保存连接绑定到全局 `materials.vision`。凭据在系统钥匙串中，不修改 `.env`；默认对话及访谈仍使用原环境模型。由于该模型已通过基础图片测试，本轮没有继续查询 NUS 其他模型或换服务商。

该结果证明当前 NUS 部署有可用图像输入，并通过这一张清晰合成页；不是数学教材、中文、复杂表格、手写公式、模糊扫描件的整体准确率报告。仍需代表性样本评测。

## 单页转录接入课程（2026-09-15）

链路：识别单页 → 人工核对通过 → 明确采用 → 资料分段分析 → 需求确认与 CourseBrief → 大纲版本 → 知识点制作读取来源 → 讲师沿用内容制作时的来源。

- 在创建课程的资料草稿中采用，也可取消或更换同页修订。保存采用记录不调用模型，和标注自动保存使用同一个前端串行写队列。未保存标注、文件版本冲突时不会覆盖用户修改。
- 只接受当前文件、当前解析、标注页段内的完整已核对结果。失败、未核对、被拒绝、存疑或声明不完整的结果不能采用。采用时再次检查源图哈希。
- 采用页的转录替换该页的本机提取文字，不双重拼接。未采用的页面继续使用本机提取文字；有识别缺口时须明确同意只使用这些文字，或缩小页段。纯扫描页可通过采用转录获得可分析内容，不再一律阻断。
- 分析发送确认展示视觉转录页数。开始分析时，把文件哈希、解析 ID、页段、识别 ID、核对修订号和内容哈希固定到 manifest；分析计划校验同时覆盖模型路由和资料修订。
- 归纳结果携带资料依据进入需求确认和大纲。搜索及内容制作按固定修订读取转录；每个片段标注视觉转录、页码和识别 ID。模型生成的来源编号不能代替服务器记录。
- 分析前改变核对状态会阻断采用该旧确认；已固定版本仍保留当时采用的修订，不因再次识别或改核对状态而静默重写。若发现旧依据错误，需要新资料/课程版本，当前尚未开放既有课程的局部替换流程。
- 讲师能看到内容制作时冻结的来源片段，不等于会主动再次检索整份教材；关键词未命中会停止制作而不是编造资料依据。向量检索、批量识别、旧课程增量补料仍为后续工作。

迁移 `20260915_06_page_adoption` 只新增页级采用表，不清空旧资料。隔离测试覆盖扫描页到需求档案/大纲输入/内容来源的传递、页段和课程边界、陈旧核对、取消采用、源图变化、内容哈希变化与同页去重。运行 `python -m unittest backend.tests.test_page_adoption`。

隔离 UI：`python -m backend.tests.serve_page_adoption_fixture`，前端代理指向 8002 后打开 `http://127.0.0.1:5175/test-fixtures/page-adoption.html`。该入口只能配合临时数据库夹具使用，使用合成页面与固定模型替身，不代表真实教材教学质量。本轮没有发送私人资料或调用真实模型。

本轮验收：178 项后端测试、49 项前端检查及构建通过；隔离页面实操“采用此页 → 核对发送范围（含采用页数）→ 分析完成”通过。新增 10 项采用链路测试，原有 PDF/DOCX 解析与文字课程流程继续通过。
